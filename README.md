Customer Churn Analysis Dashboard
📊 Project Overview
Customer churn is a critical metric for any subscription-based or service-oriented business. This project utilizes Power BI to analyze customer behavior, identifying key risk factors and segments prone to leaving. The dashboard provides actionable insights into demographics, contract types, and service usage to drive retention strategies.

🛠️ Technical Stack
Tool: Power BI Desktop

Data Transformation: Power Query (ETL, data cleaning, and normalization)

Modeling: Star Schema with dedicated Fact and Dimension tables

DAX: Implementation of complex measures for Churn Rate %, Retention Rate, and Month-over-Month (MoM) growth.

🔍 Key Business Questions Addressed
What is the current Churn Rate, and how has it trended over the last few months?

Which customer segments (Age, Gender, Tenure) are most likely to churn?

How do Contract Types (Month-to-month vs. Annual) impact customer loyalty?

Are specific Service Issues or support tickets correlated with higher attrition?

📈 Dashboard Features
Executive Summary: High-level KPIs including Total Customers, Churn Count, and Revenue Loss.

Customer Demographics: Visual breakdown of churn by gender, seniority, and dependent status.

Account Information: Analysis of payment methods, paperless billing, and tenure vs. churn correlation.

Risk Assessment: A dedicated view to identify "At-Risk" customers based on low usage or frequent support calls.

💡 Key Insights (Sample)
Contract Influence: Customers on month-to-month contracts represent the highest churn risk compared to long-term subscribers.

Tenure Impact: Significant "Early Churn" occurs within the first 6 months of the customer lifecycle.

Technical Support: Customers without online security or tech support services tend to churn at a 20% higher rate.

📂 Project Structure
Churn Data Analytics.pbix: The core Power BI file.

Data/: Folder containing the raw/cleaned dataset (if applicable).

Screenshots/: High-resolution images of the dashboard for quick preview.

🚀 How to Use
Download the .pbix file.

Open it in Power BI Desktop.

Use the Slicers (filters) on the report pages to explore churn data by specific regions or timeframes.
